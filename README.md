# Personal Investing Portal v0.1

A local-first personal portfolio design and review dashboard.

## Goals
- Review macro signals
- Review portfolio target vs current allocation
- Input holdings manually
- Classify assets by axis
- Keep raw data in local files
- Use external GPT links as a tool hub

## Not in scope
- Trading execution
- Auto-trading
- Database
- External market APIs
- Charts
- AI analysis

## Local data structure
- `app-data/config/` for definitions and targets
- `app-data/current/` for latest summaries
- `app-data/raw/` for append-only history

## Main pages
- Dashboard
- Investing
- Targets
- Asset Input
- Asset Classification
- Memory
- Settings
