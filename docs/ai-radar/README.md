# AI Radar

대화 중 발견한 AI 모델, 워크플로우, 제작자/유지보수자를 가볍게 기록하는 개인 레이더.

## 운영 원칙
- 기록 자체가 일이 되지 않게 한다.
- 모델 이름보다 **무슨 문제를 해결하는지(capability)**를 우선 기록한다.
- 링크를 발견하면 짧게 요약하고 원본 출처를 남긴다.
- 몇 달 뒤 자연어 검색으로 다시 찾을 수 있을 정도만 기록한다.
- 복잡한 점수표나 스키마는 실제 필요가 생기기 전까지 만들지 않는다.

## Files
- `models.md` — 모델/기반 기술
- `workflows.md` — 재사용 가능한 제작 워크플로우와 실전 패턴
- `creators.md` — 반복해서 유용한 작업물을 만드는 제작자/유지보수자

## Chat convention
대화 중 사용자가 `이거 기록`, `AI radar에 추가`, `이 제작자 기억해`처럼 명시하면 관련 파일을 업데이트한다.
